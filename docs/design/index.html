RoomForge Design System

화면별 디자인 갤러리

카탈로그의 21개 화면을 데스크톱·모바일 HTML 목업과 마크다운 스펙으로 구현했습니다. Charcoal surface와 muted accent 상태색을 모든 화면에 동일하게 적용합니다.

홈페이지(랜딩) ↗ 시스템 문서 원본 카탈로그
